# Username/password auth implementation plan

**Goal:** API + UI đăng nhập/đặt mật khẩu đầu tiên, phiên DB 24 giờ tuyệt đối, script bootstrap admin pending_password.
**Spec:** docs/auth-and-api-design.md; docs/database-design.md.
**Scope:** Auth đã được người dùng yêu cầu triển khai. Không thêm user CRUD, reset lượt, engine thi hoặc kết nối frontend repo khác. Không tự tạo admin thật, migrate, deploy hoặc push.

## Defaults để triển khai

- Phiên password_setup 10 phút; authenticated 24 giờ, không sliding refresh.
- Mật khẩu mới 12–128 ký tự, không trim; xác nhận trùng, khác mật khẩu tạm. Login nhận mật khẩu tối đa 128 ký tự.
- Scrypt N=32768/r=8/p=3, salt 16 byte, key 64 byte; token 32 byte ngẫu nhiên, SHA-256 tại DB.
- Login tối đa 10 lần/username và 50 lần/IP mỗi 15 phút, đếm trong PostgreSQL; IP production chỉ đọc header x-vercel-forwarded-for khi VERCEL=1, không tin header tùy ý ở local.
- Cookie host-only HttpOnly, Secure production, SameSite=Lax, Path=/; frontend production phải cùng site, origin allowlist cụ thể. Origin/JSON checks cho mutation, no-store cho mọi response.
- Login lỗi chung; kiểm tra password hash trước rồi khóa/recheck user khi cấp phiên. Kích hoạt khóa user trước session, đổi mật khẩu/thu hồi/cấp phiên trong transaction.
- Script tạo username mới role admin, pending_password và mật khẩu tạm ngẫu nhiên, không overwrite user cũ; secret chỉ xuất một lần tại terminal khi thành công.

## Validation

npm test; npm run typecheck; npm run lint; npm run format:check; npm run db:check; npm run db:generate; npm run build -- --webpack.
PGlite dùng SQL thật và transaction nhưng không chứng minh tranh chấp nhiều connection trên Neon. Kiểm thử race trên Neon/PostgreSQL riêng khi có credentials; không dùng production.

## Verification results

- 53 tests pass across SQL schema, password/token, auth service, HTTP and DOM forms.
- Typecheck, ESLint, Prettier and drizzle-kit check pass; generation reports no schema changes (still 8 tables).
- Production build passes with Webpack and contains login/setup/account/admin plus the four dynamic auth endpoints.
- Production server smoke: /login 200, anonymous /admin, /setup-password and /account each redirect 307 to /login.
- Bootstrap CLI usage exits safely without connecting to DB; provisioning is exercised against PostgreSQL embedded.
- Reviewed auth independently; setup hashing limiter added before expensive derivation, with a regression test shared across setup sessions. Denied IP requests do not allocate additional username buckets.
- Scanned 33 client assets: no source bank prompt samples, answer-authority fields or server verifier constants.
- No production migration, admin creation, deploy, commit or push performed. Driver/cookie domain and true multi-connection races still require a separate Neon test environment.
